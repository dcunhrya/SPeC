# SPeC — The Stanford Biomedical Perception Challenge

Landing page for **SPeC**, a community benchmark for advancing perception, reasoning, and clinical understanding in biomedical AI.

## Live site

Once GitHub Pages is enabled, the site is available at:

**https://dcunhrya.github.io/SPeC/**

## Local development

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Structure

- `index.html` — main landing page
- `css/styles.css` — styles
- `js/main.js` — mobile navigation
